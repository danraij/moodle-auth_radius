# About this plugin

A simple plugin to allow authenticating against a RADIUS server.

# About this fork

Originally this plugin used to be part of Moodle core but was removed and is no longer being maintained. My aim with this fork is to bring it up do date for Moodle 4.5 since it's the currently supported LTS version.
